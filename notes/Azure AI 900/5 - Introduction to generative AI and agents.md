# Large language models (LLMs)
- encapsulate the linguistic and semantic relationships between words and phrases
- LLMs are trained to generate completions based on prompts
- **prompt**: starts a sequence of text of text predictions that results in semantically correct completion
- the model understands the relationship between words and can identify which words are most likely to influence the next one

## Tokenization
- first step is to provide the model with a large vocabulary of words
- latest generations of LLMs consts of hundreds of thousands of tokens
- LLMs break down their vocabulary into tokens
- first step in training an LLM is to break text into distinct tokens
- tokens include
	- words,
	- sub-words (un in unbelievable)
	- punctuation
	- commonly used sequences of characters

## Transforming tokens with a transformer
- we need a way to relate tokens to each other
- each token is assigned a vector
- each vector has numeric elements or dimensions
- we can use these to encode linguistic and semantic attributes to help provide information about what the token means and how it relates to other tokens
- we need to transform the initial vector representations of tokens into new vectors with linguistic and semantic characteristics embedded

We use a transformer model
- **encoder**: block that creates the embedding by applying a technique called attention
- **decoder**: layer that uses the embeddings calculated to determine the next most probably token in a sequence

## Initial vectors and positional encoding
- the token vector values are assigned randomly before being fed through the transformer
- the token vectors are fed into the transformer along with positional encoding
- positional encoding: indicates where the token appears in the sequence of training text

## Attention and embeddings
- the transformer uses attention layers to determine the vector representations of tokens
- attention layer considers each token in turn within the context of the sequence of tokens
- the tokens around the current one are weighted to reflect their influence
- the weights are used to calculate the element values for the current token's embedding vector
- Initially, the model doesn't know which tokens influence others
- as it's exposed to larger volumes of text, it can learn which tokens commonly appear together

## Predicting completions for prompts
- we can use the decoder block to iteratively predict the next word in a sequence based on the starting prompt
- the decoder model is trained by applying a technique called masked attention
- masked attention: the tokens after the current token are ignored
- when predicting a new completion, the attention layers calculate possible vectors for the next token and the feed-forward network is used to help determine the most probable candidate
# Prompts
- the input you give an LLM to get a response
## Types of prompt
- System prompts: set the behaviour and tone of the model, and any constraints they should adhere to
- User prompts: elicit a response to a specific question or instruction

Usually the system prompt is set by the application that uses the model. User prompts are entered by a user in a chat application, or in some cases may be generated by the application on a user's behalf

## Conversation history
- generative AI apps keep track of conversation history
- summarized version are included in subsequent prompts
- ensures ongoing context for the conversation the model can build on

## Retrieval augmented generation (RAG)
- RAG can be used to add even more context
- involves retrieving information, like documents or emails, to augment the prompt with relevant data
- the response is grounded in the information it was provided
![[Pasted image 20251218204117.png]]
## Tip for better prompts
- the quality of responses depend on the language model and the prompts used
- to get better results:
	- be clear and specific - provide explicit instructions
	- add context - mention the topic, audience, or format
	- use examples - provide an example of what you mean
	- ask for structure - like bullet points, tables, or numbered lists

# AI agents
- software applications built on generative AI that can
	- reason over and generate natural language
	- automate tasks by using tools
	- response to contextual conditions and take appropriate actions
## Components of an AI agent
- **A large language model**: the agent's brain, using generative AI for language understanding
- **Instructions**: system prompt that defines the agent's role and behaviour
- **Tools**: what the agent uses to interact with the world
	- Knowledge tools that provide access to information (search engine, databases)
	- Action tools that enable the agent to perform tasks
- AI agents can take on the role of digital assistants that automate tasks and collaborate with you to work smarter

## Multi-agent systems
- multiple agents can collaborate each with its own specialty
- one might gather data, one analyze, and another takes action
- they can handle complex workflows like a human team
- they communicate with each other through prompts, using generative AI to determine what tasks are required and which agents are responsible for completing them
