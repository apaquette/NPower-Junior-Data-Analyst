## Introduction to Spreadsheets
- common spreadsheet applications
	- Excel
	- LibreOffice Calc
	- Google Sheets
	- Zoho Sheet
	- Apple Numbers
- Data can be easily formatted, filtered, and sorted
- Easy to edit or undo mistakes
- Visualisations can be created (charts, graphs, reports)
- Common business uses
	- Data Entry and Storage
	- Comparing Large Datasets
	- Modelling and Planning
	- Charting
	- Identifying Trends
	- Flowcharts

## Spreadsheet Basics
- Workbook: one or more worksheet
- Worksheets are made up of cells
- Cells contain data (text, numbers, formulas, results)
- Cells are organised in columns and rows
- Each cell has a reference comprised of its column/row coordinate

## Using Spreadsheets as a Data Analyst Tool
- Can be useful in the right context
- has its limitations
- pro
	- can see the data cleanly laid out
	- easy to determine what the data is
	- great for simple analysis
	- good for up to 20k lines of data
- limitations
	- difficult to reproduce state
	- no way to tell what steps were taken on the data
	- too many functions (can find yourself in analysis paralysis)
	- complex formulas sometimes stop working
	- good for simple analysis only
## Summary and Highlights
- There are several spreadsheet applications in the marketplace (most common is Excel)
- Spreadsheets provide advantages over manual calculation methods and help keep data organised
- You can use spreadsheets as a tool for data analysis tasks
