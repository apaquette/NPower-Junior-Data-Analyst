## Basics of Data Privacy
- Confidentiality
	- acknowledges the customer's personal information belongs to them
	- Personal Information: information that can be tracked to a specific individual
	- Personally Identifiable Information: information that could be used to identify an individual
	- Sensitive Personal Information: contains private information that needs to be protected
- Collection and Use
	- GDPR (General Data Protection Regulation): specific to the EU
	- LGPD: Specific to Brazil
	- CCPA: California
- Compliance
