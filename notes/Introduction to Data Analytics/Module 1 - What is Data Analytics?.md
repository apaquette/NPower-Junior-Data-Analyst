# Modern Data Ecosystem and the Role of Data Analytics
## Modern Data Ecosystem
- Whole network of interconnected entities
- Data that needs to be integrated from disparate sources
- Types of Data: Structured and unstructured
- Processing Steps:
	- copy data into a repository
	- organise, clean, and optimise access
		- *must be compliant to standards enforced*
	- create ways for stakeholders to access and interface the data
## Key Players in the Data Ecosystem
- Data Engineers
	- Tasks: Converts raw data into usable data
	- Skills: programming, systems and tech architectures, relational and non-relational databases
- Data Analyst
	- Tasks: generate insights from data
	- Skills: Spreadsheets, queries, statistical tools, dashboards
- Data Scientist
	- Tasks: predict the future using data from the past
	- Skills: mathematics, statistics, programming, databases, data models
- Business Analysts
	- Tasks: use insights and predictions to drive decisions that benefit the business
	- Skills: 
## Defining Data Analysis
- the process of gathering, cleaning, analysing and mining data, interpreting results, and reporting findings
- businesses validate a course of action before committing to it using data analysis
- Predictive analytics: uses historical data and trends to predict future outcomes

## Summary and Highlights

Modern data ecosystem includes a network of connected and evolving entities that include:
- Data in a host of different formats, structure, and sources
- Enterprise Data Environments where raw data is staged to be categorised, cleaned, and optimised
- End-users who consume data for various purposes

Emerging technologies are continually reshaping the data ecosystem. Data Engineers, Data Analysts, Data Scientists, Business Analysts, and Business Intelligence Analysts all play a role in the ecosystem.

Based on the goals and outcomes, there are four primary types of Data Analysis:
- Descriptive (What happened)
- Diagnostic (Why it happened)
- Predictive (What will happen next)
The process involves:
- Understand the problem and the desired outcome
- Set metrics for evaluating outcomes
- Gather, clean, analyse, and mine data
- Communicate findings

## Data Analytics vs Data Analysis
Analysis - *detailed examination of elements or structure of something*
Analytics - *systematic computational analysis of data or statistics*

# The Data Analyst Role
## Responsibilities of a Data Analyst
- Acquiring data (primary and secondary sources)
- Creating queries for data extraction
- Filtering, cleaning, standardising, and organising data
- Use statistical tools to interpret data
- Analysing patters and interpret trends
- Prepare reports and charts to communicate trends and patterns

### Technical Skills
- Use spreadsheets
- Statistical analysis and visualisation tools
- Programming languages ([[R]], [[Python]])
- Relational databases ([[SQL]]), an NoSQL databases
- Familiarity with Big Data processing tools (Hadoop, Hive, Spark)

### Functional Skills
- Statistics (analyse data, validate analysis, identify fallacies)
- Analytical skills
- Problem-solving skills
- Data visualisation skills
- Project management skills

### Soft Skills
- Work collaboratively
- Communicate effectively
- Curiosity

## Generative AI
- a class of artificial intelligence models that create new content
- can respond naturally to human conversation
- How does it work
	- starts with a prompt (text, image, video, etc.) for processing
	- AI algorithms return new content (essays, solutions, realistic fakes, etc.)

**Generative adversarial networks (GANs)**: consist of two neural networks: the generator and discriminator. The generator creates data, and the discriminator evaluates it.
**Variational autoencoders (VAEs)**: Encode input data into a compressed format then decode it back, generating new data points similar to the input data.
**Transformers**: Used in natural language processing (NLP), generate human-like text by predicting the next word in a sequence.

### Uses Cases
- Implementing customer chatbots (customer service, technical support)
- Deploying deepfakes
- Improving dubbing in different languages
- Writing email responses, dating profiles, resumes, and term papers
- Creating photorealistic art

### Benefits
- Automating content writing process
- Low-effort email response
- Improved responses to technical queries
- Summarising complex information
- Simplifying content creation process

### Limitations
- Does not always identify the content source
- Challenging to assess the bias of original sources
- Difficult to identify inaccurate information
- Difficult to understand how to tune
- Results can gloss over bias, prejudice, and hatred

### Concerns
- provide inaccurate or misleading information
- More difficult to trust
- Can promote new kinds of plagiarism that ignore rights of content creators
- Disrupt existing business models
- Easier to generate fake news
- Easier to claim real photographic evidence was AI-generated fake

### Examples of Gen AI tools
- Text generation (GPT, Jasper, Lex)
- Image generation (Dall-E, Midjourney, Stable diffusion)
- Music generation (Amper, Dadabots, MuseNet)
- Code generation (Codex, Copilot)
- Voice synthesis (Descript, Listnr)

### Applications of generative AI in data analytics
**Data augmentation**: Create synthetic data to augment existing datasets
**Anomaly Detection**: Identify anomalies or outliers
**Text and image generation**: Generate realistic text
**Simulation and forecasting**: Simulate scenarios and forecast future events

## Summary and Highlights
The role of a Data Analyst spans:
- Acquiring data that serves the user case
- Preparing and analysing data
- Interpreting and communicating the message to stakeholders
- Ensuring the process is documented

Data Analysts need a mix of technical, functional, and soft skills
- Technical skills include spreadsheets, statistical tools, visualisation, programming, and querying languages, and the ability to work with different types of data repository
- An understanding of Statistics, Analytical techniques, problem-solving, ability to probe a situation, data visualisation, and project management skills
- Soft skills include collaboration, communication, curiosity
