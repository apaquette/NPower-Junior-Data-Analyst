# String Operations
- use double or single quotes
	- "this is a string"
	- 'this is also a string'
- string behave like character arrays
- you can go forwards (0 to n) or backwards (-1 to -n)
- you can slice strings
	- Name[0:4] take characters 0 to 3
- Name[::2] means take every second value
- Name[0:5:2] take every second value up to index 4
- len(str) gives the length of the string
- addition (+) combines string together
- multiplication (* ) multiplies strings
	- 3 * "a" = "aaa"
- strings are immutable, they cannot be modified after creation
- escape sequences are preceeded by backslash (\ )
	- \n newline
	- \t tab
	- \ \ insert a backslash
## String Methods
- upper() converts all characters to upper case
- .replace(a, b) replaces substring a with value of b
