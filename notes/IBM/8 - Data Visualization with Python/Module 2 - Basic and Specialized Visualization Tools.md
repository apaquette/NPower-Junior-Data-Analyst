# Basic Visualizations
## Area Plots
- aka area chart or graph
- displays magnitude and proportion of multiple variables
- represent time or another ordered dimension
- based on the line plot
## Histograms
- represents the frequency distribution of a dataset
- partitions numeric data into bins
- assigns each data point in the dataset
- counts the number of data points
## Bar charts
- aka bar graph
- compares values of a variable

## Understanding Treemaps and Pivot Charts
### Treemaps
- Display hierarchical data using nested rectangles
- Each branch of the hierarchy is given a rectangle, and is filled with smaller rectangles for sub-branches
- Useful for visualizing large datasets where hierarchical structure is crucial
### Pivot Charts
- Allow users to dynamically summarize and explore large datasets
- Widely used in business intelligence, finance, and various other fields
