# Advanced Visualization Tools
## Waffle Charts
- Represents categorical data in the form of square tiles and cells
- Display proportion or percentage of difference categories
- Simplifies data for all types of audiences
## World cloud
- Presents a concise summary of textual content
-  Provides an overview of most commonly used words
- Depicts the importance of difference words
- Bigger/bolder words appear more frequently
## Seaborn & Regression Plots
- Visualization library based on Matplotlib
- Offers built-in themes and color palettes to improve visuals
- Visuals needing 20 lines of code with Matplotlib is reduced 5-fold with Seaborn
- Special Plots: Regression, Distribution, Categorical, Scatter plots w/ Regression lines
# Visualizing Geospatial Data
## Introduction to Folium
- Data visualization Python library for geospatial data
- Can create a map using latitude and longitude values
- Can also create maps of different styles (street-level, stamen, and others)
- Maps are interactive, enabling zooming and panning
## Choropleth Maps
- Thematic map where areas are shaded by proportion
- Darker colour indicates higher value
- A GeoJson File is needed to create the map
