# Creating Advanced Charts
## Creating Tree maps, Scatter Charts, and Histograms
- Tree map
	- used to compare values across hierarchy levels
	- good way of displaying lots of data in one graphical asset
- Scatter chart
	- used to compare two sets of numerical data
	- shows relationship between the two sets
	- combines the sets on x and y axes into a single point and displays them in clusters
	- sometimes referred to as xy charts
- Histogram
	- shows the distribution of data grouped into bins
	- looks like a column or bar chart, but isn't
	- used to display distribution data
## Creating Filled Map Charts and Sparklines
- filled map
	- type of chart used to compare values and show categories across geographical regions
	- suitable for data containing geographical regions
- sparklines
	- show data trends
	- can also be used to highlight max-min values
	- provides the greatest impact when placed close to the data it represents

# Creating Dashboards Using Spreadsheets
## Dashboards
- put key business information in one place using graphical displays
- makes it easier for the viewer to understand
- can allow users to interact with the dashboard and modify the information they see
- users get a consolidated visualization of their data, and a controllable self-service business intelligence (BI) interface
- typically created in a data analysis application
