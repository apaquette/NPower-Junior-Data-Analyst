- Equal sign starts a formula
- SUM: adds up values in referenced cell or ranges
- Arithmetic operators
	- addition (+)
	- subtraction (-)
	- multiplication (asterisk)
	- division(/)

## Referencing Data in Formulas
- cell references are always relative by default (B2)
- Absolute reference ($B$2)
- Can also reference just a column ($B2) or row (B$2)

## Summary and Highlights
- Several features to modify views in Excel, and it's straightforward to enter and edit data
- You can move or copy data within a worksheet or between worksheets, and can use AutoFill to enter data in a series or that fits a pattern
- You can format both cells and data
- A formula is made up of several component parts, and formulas can perform calculations using numbers directly or by using references
- You can use the Fill Handle to quickly copy formulas
- There are several categories of function you can use for different purposes
- You can reference cells in worksheets by using relative, absolute, or mixed references
- You can make a formula absolute by adding a dolar symbol ($) to a cell reference
- If you get errors in you formulas, you can use the error-checking capabilities to solve them
