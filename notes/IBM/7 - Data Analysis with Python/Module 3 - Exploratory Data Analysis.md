# Exploratory Data Analysis
- EDA: steps in data analysis to
	- summarize main characteristics of the data
	- gain a better understanding of the data set
	- uncover relationships between variables
	- extract important variables
# Descriptive Statistics
- explore data before building complicated models
- calculate descriptive stats for your data
- describe basic features
- give short summaries about the sample and measures of the data
- `describe()`: summarize stats using pandas
- `value_counts()`: summarize categorical data
- Box plots: great for visualising numerical data
- Scatter plots
	- each observation is represented as a point
	- shows the relationship between two variables (predictor and target)
	- matplotlib `scatter(x,y)`
# GroupBy in Python
- `dataframe.groupby()` pandas method
	- can be applied to categorical variables
	- group data into categories
	- single or multiple variables
- `pivot()`: Pandas method
	- one variable is displayed along the columns, the other along rows
	- similar to excel spreadsheets
- heatmap
	- plot target along multiple variables
	- pyplot `pcolor()` method
# Correlation
- measures the extent different variables are interdependent
- correlation doesn't imply causation
- positive linear relationship
	- illustrate positive relationship between variables
	- indicated by a positive "upward" line trend
- negative linear relationship
	- illustrate negative relationship between variables
	- indicated by a negative "downward" line trend
- weak linear correlation
	- indicated by a somewhat level line trend
	- not steep enough slope to indicate either negative or positive trend
