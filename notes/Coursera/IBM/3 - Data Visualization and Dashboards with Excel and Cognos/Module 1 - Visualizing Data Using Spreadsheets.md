## Introduction to Charts
- Line chart
	- great way to display information
	- able to show trends and value changing in relation to a continuous variable
- Pie chart
	- show the breakdown of an entity into sub-parts
	- each portion represents a static value
	- sum of all categories equals 100%
- Bar Chart
	- most common type of chart
	- easy to create
	- great for comparing related data sets
	- Stacked bars: each bar is divided into sub bars
- Column chart
	- horizontal version of bar chart
	- effectively shows change over time and compare values
	- may be better suited for showing negative and positive values
- Treemaps
	- useful for displaying complex hierarchies
- Scatter chart
	- dots represent categories of data and the size indicates the volume
	- can be great for showing trends, clusters, patterns, and correlation
- Bubble charts
	- variant of scatter charts
	- useful for comparing handful of categories to one another
- Sparklines
	- great for showing general trend of a variation
